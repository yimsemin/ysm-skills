# riso-illustration

시작 전에 [화풍과 프롬프트 기준](references/style.md)을 읽고 요청에 적용할 기준을 정한다.

- 사용자가 지정한 프로젝트 스타일 가이드의 화풍·팔레트·캐릭터 기준을 우선한다.
- 이 스킬의 실무자·관리자·청록색 AI를 요청하거나 해당 캐릭터가 나오는 삽화를 이어 그리면 [캐릭터 시트](references/character-sheet.md)의 외형과 Office Notes Cartoon × 리소그래프 화풍·팔레트를 적용한다. 사용자 가이드에서 별도로 정한 항목은 그 기준을 따른다.
- 별도 기준이 없는 작업은 기본 투컬러 리소그래프 화풍과 팔레트를 사용한다.

## 1. 요청 정리

사용자 말에서 아래만 뽑고, 빠진 것은 묻지 말고 가정해 밝힌다.

- **주제와 장면**. 문서용이면 최신 본문에서 독자에게 전달할 메시지 하나를 고른다. 참조 이미지를 보기 전에 그 메시지가 드러나는 상황과 구도(시점·거리·인물 배치)를 정한다. 정확한 비교·절차에는 편집 가능한 도해, 실제 화면에는 검증된 캡처가 맞는지 판단한다.
- **용도와 비율**. 프로필 1:1, 일반 본문 3:2, 대표 이미지 16:9를 기본으로 삼고 사용처와 사용자 지시를 우선한다.
- **참고 이미지**. 장면을 정한 뒤 적용할 캐릭터 시트에서 등장인물의 이미지를 열고, 사용자 지정 기준 삽화가 있으면 함께 확인한다. 외형·비율·기본 복장과 해당 화풍을 계승한다. 구도·시점·배치·행동·배경은 새 장면에 맞춰 설계한다. 참조 원본은 제공된 위치에서 사용한다.
- **결과 형태**. 후보 비교가 목적이면 지정한 수만큼 만들고 수를 정하지 않았으면 4장으로 한다. 한 장이나 최종 삽입을 요청하면 용도별 최종 이미지까지 진행한다.

## 2. 도구 확인

이 세션에 이미지를 생성·편집하는 도구가 있는지 확인한다. 없는 것을 설치·연결하거나 새 API·유료 서비스·MCP 서버를 쓰자고 하지 않는다.

- 생성 도구가 있으면 실제로 생성한다. 도구가 이미지 입력을 지원하면 확인한 공개 참조를 첨부한다. 비공개 참조는 사용자가 도구로 전송된다는 점을 알고 있을 때 넘긴다.
- 참조를 확인하거나 첨부할 수 없으면 시트의 외형·비율·색을 프롬프트에 적고 적용하지 못한 참조를 보고한다.
- 생성 도구가 없으면 그 사실을 첫머리에 밝히고 3절의 프롬프트와 비율 등 필요한 옵션을 낸다. 후보 프롬프트는 번호별 코드 블록으로 제시한다.

## 3. 생성과 검수

`style.md`의 프롬프트 골격을 사용한다. 새 장면과 구도를 1~2문장으로 쓰고 화풍·팔레트·참조 범위·비율을 덧붙인다. 생성에 필요한 시각 지시만 전달한다.

- 후보의 구도·시점·동작·장면 구성 중 둘 이상을 실질적으로 다르게 잡는다. 승인된 캐릭터 외형과 화풍·팔레트를 공통으로 적용한다.
- 최종 이미지와 각 후보는 한 장씩 생성하고 사용처에 맞는 래스터 형식(예: PNG, WebP)으로 저장한다. 저장 위치가 정해지지 않았으면 프로젝트 안 `illustrations/<주제>/`에 저장하고, 후보는 `후보-1`, `후보-2`처럼 번호를 붙인다.
- 첫 결과부터 `style.md` 기준으로 직접 검수한다. 기준에 미달하면 원인을 짚어 수정하거나 다시 생성한다. 기본은 초기 생성과 보정 1회다. 같은 문제가 반복되면 장면이나 프롬프트를 다시 설계하고 적합한 결과가 없으면 그 이유를 알린다.

## 4. 후보 제시와 수정

생성한 후보의 파일과 구도 차이를 번호별로 보여 준다.

선택한 후보의 프롬프트와 파일을 기준으로 삼는다. 요청한 부분만 바꾸고 나머지(구도, 인물 특징, 팔레트)는 유지하도록 프롬프트에 "유지할 것"을 명시한다.

- 편집을 지원하는 도구면 선택 이미지를 입력으로 편집한다. 아니면 선택 후보의 프롬프트에 변경점을 더해 다시 생성한다.
- 수정 후보를 비교하는 경우 기본 2~4장을 제시한다. 한 장을 요청하면 한 장을 낸다.

## 5. 결과 전달과 삽입

최종 이미지 제작과 삽입을 함께 요청받으면 검수를 통과한 이미지를 골라 삽입과 저장 확인까지 진행한다. 시안이나 이미지 파일 요청은 해당 결과를 전달하면 완료다. 삽입 직전에 최신 본문을 확인하고 관련 설명 가까이에 원본 화질을 유지해 배치한다. 그림이 전달하는 내용을 대체 텍스트로 작성하고 기존 편집을 보존한다.

이미지 품질, 파일과 본문 참조·대체 텍스트의 저장 상태, 실제 화면에서의 배치·가독성을 각각 확인한다. 실제로 확인한 결과와 확인할 수 없었던 항목을 보고한다.
