# 문구 점검 체크리스트

- [ ] 문구 전수 나열을 만들어 끝까지 읽었다
- [ ] 코드에 박힌 사용자용 문자열을 찾았다
- [ ] 언어 간 누락·미사용 키, 변수 불일치를 확인했다
- [ ] 문구로 오류 종류를 판별하는 코드를 찾았다
- [ ] 모든 언어를 처음부터 끝까지 실제로 실행했다(못 한 것은 기록)
- [ ] 안내된 명령·경로를 그대로 실행해 봤다
- [ ] 인용된 버튼·메뉴 이름을 화면과 글자 단위로 대조했다
- [ ] 요청문·CLI 안내·지침 파일을 같은 기준으로 봤다
- [ ] 결함을 유형별로 분류하고 우선순위를 정했다
- [ ] 보고: 결정 항목 / 유형별 내용 / 확인하지 못한 것 / 하지 않은 것
